# RIMS — Bản trình diễn (static)

Bản đóng gói tĩnh của giao diện RIMS (Reservoirs Integrated Management System) phục vụ trình diễn.
Deploy dạng **static site** (không backend). Các lớp dữ liệu trực tiếp (trạm RMA, RainLab, HNT live) tắt;
luồng demo "Liên hồ — Hệ thống sông Ngàn Sâu" chạy hoàn toàn bằng dữ liệu tĩnh đã nhúng.

Publish directory: thư mục gốc repo (chứa index.html). Không cần build.
